# 息屏万年历（calendarsleepscreen.koplugin）

KOReader 插件：设备息屏（休眠屏）时显示当月万年历（公历 + 农历）、当前时间与日期，节日一目了然。

## 关于本版本

本插件基于开源 `calendarsleepscreen` 息屏万年历插件修改增强，版权归原作者所有。
采用 AGPL-3.0 许可发布，允许自由使用、修改与再分发（须保留本声明）。

本增强版新增 / 修复：
- 修复息屏万年历"首次显示、后续不显示"问题（重置 device.screen_saver_mode）
- 充电时息屏时间/日期**每分钟持续刷新**（凌晨 1:00–7:00 自动暂停省电）
- 未充电时真挂起省电（时间停在息屏那一刻）
- 充电息屏唤醒后**背光自动亮起**（实测适配 Paperwhite 3 / max77696-bl）

使用注意：
- 充电时请勿连续按电源键（Kindle 电源状态机可能紊乱：屏幕不灭/点不亮），
  正确做法是一下一下按；若乱了，拔掉充电器或重启 KOReader 即可恢复。
- 背光唤醒修复实测针对 Paperwhite 3；其他型号万年历可用，但充电唤醒背光可能不自动亮。

## 功能

- 息屏时显示：大号当前时间、公历日期与星期、农历（干支年 / 生肖 / 农历月日）
- 当月万年历网格：公历日 + 农历日对照，每月初显示农历月名，节日直接标注
- 当天黑底高亮
- 支持元旦、劳动节、国庆、春节、元宵、端午、中秋、除夕等常用节日（息屏格子内显示 3 字以内名称）
- 未启用或构建异常时自动回退 KOReader 原生睡眠屏，不影响关机 / 重启流程

## 安装

1. 将整个 `calendarsleepscreen.koplugin` 文件夹复制到 KOReader 的插件目录：
   - 通常是 `settings.reader.lua` 所在目录（KOReader 数据目录）下的 `plugins/` 文件夹；
   - 或 KOReader 安装目录下的 `plugins/` 文件夹。
2. 启动 KOReader：工具（扳手图标）→ 插件管理 → User plugins → 勾选「息屏万年历」→ 重启 KOReader。
3. 再次进入：工具 → 息屏万年历 → 勾选「启用息屏万年历」（默认关闭，需手动启用）。
4. 可点「预览效果」在亮屏状态下查看息屏样式，点按或按任意键退出预览。

## 已知限制

- 电纸书休眠后系统与屏幕均停止刷新，**时间停留在进入息屏那一刻**；唤醒后再息屏会自动更新为新时间。
  这是硬件特性，不是插件缺陷。
- 插件不会定时唤醒设备刷新屏幕（避免持续耗电）。
- 农历数据支持 1900–3000 年。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `main.lua` | 插件入口：息屏接管、万年历绘制、菜单与设置 |
| `calendarsleepscreen_lunardate.lua` | 公历 ↔ 农历转换、日历网格（纯 Lua，兼容 LuaJIT） |
| `calendarsleepscreen_lunarinfo.lua` | 农历压缩数据表（1900–3000） |
| `_meta.lua` | 插件元信息 |

农历算法移植自广泛验证的 JJonline/calendar.js（含 2033 闰冬月、2057 修正数据），并经真值对照与随机抽样验证。
